# Entwicklungsumgebung einrichten

Für die Mitarbeit am Projekt werden Java 25, Node.js, Docker, Maven und eine IDE benötigt.

## Paketmanager

Wir installieren alles über einen Paketmanager statt über einzelne Installer. Das spart das manuelle Setzen von `JAVA_HOME` und `Path`, und Updates gehen mit einem Befehl.

<Tabs groupId="os">
  <TabItem value="mac" label="macOS">
    [Homebrew](https://brew.sh/) installieren, falls noch nicht vorhanden:
    ```bash
    /bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
    ```
  </TabItem>
  <TabItem value="win" label="Windows">
    [Scoop](https://scoop.sh/) installiert Programme ohne Administratorrechte in den Benutzerordner und setzt Umgebungsvariablen selbst. In einer PowerShell (**nicht** als Administrator):
    ```powershell
    Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser
    Invoke-RestMethod -Uri https://get.scoop.sh | Invoke-Expression
    ```
    Scoop braucht Git, um weitere Paketquellen (*Buckets*) einzubinden. Das JDK liegt im Bucket `java`:
    ```powershell
    scoop install git
    scoop bucket add java
    ```
    Alle mit Scoop installierten Programme aktualisieren: `scoop update *`
  </TabItem>
</Tabs>

## Java 25

Als JDK-Distribution empfehlen wir [Eclipse Temurin 25](https://adoptium.net/) (OpenJDK, kostenlos, von der Adoptium-Community gepflegt).

<Tabs groupId="os">
  <TabItem value="mac" label="macOS">
    ```bash
    brew install --cask temurin@25
    ```
    Installation prüfen:
    ```bash
    java -version
    ```
  </TabItem>
  <TabItem value="win" label="Windows">
    ```powershell
    scoop install temurin25-jdk
    ```
    Scoop setzt dabei auch `JAVA_HOME`. Danach ein neues Terminal öffnen und prüfen:
    ```powershell
    java -version
    ```
  </TabItem>
</Tabs>

## Docker

[Docker Desktop](https://www.docker.com/products/docker-desktop/) stellt sowohl die Docker Engine als auch Docker Compose bereit.

<Tabs groupId="os">
  <TabItem value="mac" label="macOS">
    ```bash
    brew install --cask docker
    ```
    Anschließend Docker Desktop aus dem Launchpad starten. Docker läuft im Hintergrund als Menüleisten-App.
  </TabItem>
  <TabItem value="win" label="Windows">
    Docker Desktop ist die Ausnahme: Scoop bietet nur die Docker-CLI ohne Engine. Daher den Installer von [docker.com/products/docker-desktop](https://www.docker.com/products/docker-desktop/) herunterladen und ausführen.

    Docker Desktop benötigt unter Windows das **WSL 2**-Backend (wird beim Setup automatisch eingerichtet, sofern noch nicht vorhanden).
  </TabItem>
</Tabs>

Installation prüfen:
```bash
docker run hello-world
```

### CIB seven Maven Repository einrichten

:::warning[Pflichtschritt für CIB seven Services]
Das CIB seven Enterprise Repository ist nicht öffentlich zugänglich. Ohne diese Konfiguration schlägt der Maven-Build aller Services fehl, die auf dem [cibseven-template](https://github.com/d135-1r43/cibseven-template) basieren. Zugangsdaten (Kundennummer + Passwort) beim Dozenten erfragen.
:::

Die Zugangsdaten werden einmalig in `~/.m2/settings.xml` hinterlegt:

**In `<servers>` einfügen:**
```xml
<server>
  <id>mvn-cibseven-enterprise</id>
  <username>KUNDENNUMMER</username>
  <password>PASSWORT</password>
</server>
```

**In `<profiles>` einfügen:**
```xml
<profile>
  <id>cibseven-ee</id>
  <repositories>
    <repository>
      <id>mvn-cibseven-enterprise</id>
      <name>CIB seven Enterprise repository</name>
      <url>https://artifacts.cibseven.org/repository/enterprise-group/</url>
    </repository>
  </repositories>
</profile>
```

**In `<activeProfiles>` einfügen:**
```xml
<activeProfile>cibseven-ee</activeProfile>
```

## IDE: IntelliJ IDEA

Wir empfehlen [IntelliJ IDEA](https://www.jetbrains.com/idea/) als Entwicklungsumgebung. Die **Community Edition** ist kostenlos und für dieses Projekt ausreichend. Allerdings fehlen sehr komfortable Features zum Entwickeln mit Spring und Quarkus. Daher sollte die **Ultimate Edition** verwendet werden. 

Als Studierende der THI besteht Anspruch auf die **Ultimate Edition**, kostenlos über das [JetBrains Student Program](https://www.jetbrains.com/community/education/#students).

IntelliJ erkennt Maven-Projekte automatisch beim Öffnen und bringt ein integriertes Terminal, Git-Unterstützung und Debugger für Spring Boot mit. Das JDK kann direkt in IntelliJ unter **File → Project Structure → SDK** verwaltet werden.

IntelliJ ist dabei nur ein Fenster auf einen Ordner. Was das für die Arbeit mit Git bedeutet, beschreibt [Der Checkout ist nur ein Ordner](./git-checkout).
